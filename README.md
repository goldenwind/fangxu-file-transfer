# 方序传文件

> 方寸之间，传递有序。

方序传文件是一款免费、简洁的局域网文件传输工具。Windows、macOS 或 Linux 电脑共享一个目录，Android、iPhone 或 iPad 无需安装 App，打开系统浏览器即可上传和下载文件。

## 适用场景

- **电脑与手机互传**：把电脑上的文档、电子书、视频或安装包下载到手机，也可把手机照片、资料上传到电脑的共享目录。
- **不同系统之间临时传文件**：例如 Windows 与 iPhone、macOS 与 Android，或 Linux 与平板，不必为每台移动设备安装客户端。
- **同一网络内分享资料**：家庭设备互传、会议资料分发、课堂资料共享；接收者扫码后自行浏览、搜索并下载需要的文件。
- **不想经过云端**：设备之间能通过局域网连接即可，不依赖互联网连接，也无需先上传网盘再下载。

最适合：**设备在同一可信局域网中，想临时、直接地传文件，且不希望手机安装额外 App。**

## 本项目的优势

| 优势 | 对使用者意味着什么 |
| --- | --- |
| 手机只需浏览器 | 不用注册账号、安装 App 或连接数据线，扫码即可打开 |
| 跨平台 | 电脑支持 Windows、macOS、Linux，移动端使用系统浏览器访问 |
| 文件直接传输 | 不经过第三方服务器，不占网盘空间；实际速度取决于局域网和设备性能 |
| 共享整个目录 | 不用逐个发送，接收者可以按名称搜索、按类型筛选，并选择排序方式 |
| 双向传输 | 同一个页面支持下载与多文件上传，上传同名文件自动追加序号 |
| 随用随停 | 双击启动、页面设置目录、查看状态；点击停止按钮后服务退出，不持续开放共享 |
| 操作克制 | 网页不提供删除、重命名，减少误操作原文件的风险 |

### 使用边界

- 这是临时文件传输工具，不是公网网盘、自动同步工具或备份系统。跨网络、异地传输请使用其他方案。
- **默认未开启访问令牌保护**：能连接服务地址的设备可以浏览、下载及上传文件。多人网络中请先开启保护，再分享新二维码或完整链接。
- 访问令牌只是共享链接的“钥匙”，**不是传输加密**。本工具使用 HTTP，不建议在公共 Wi-Fi 中传输敏感文件。
- 共享目录及其非隐藏子目录中的文件会对访问者开放，请选择专用目录，不要直接共享包含私人资料的目录。上传的文件也会出现在共享列表中；不要随意运行他人上传的程序。
- 下载后能否打开文件、安装应用，取决于接收设备支持的格式与系统限制；传输成功不代表格式兼容。

## 其他传文件方法与选择建议

不同场景适合不同工具，方序传文件并不是所有传输方式的替代品：

| 方法 | 更适合的场景 | 使用要点与取舍 |
| --- | --- | --- |
| 数据线 / USB | 大批量文件、没有可用局域网 | 连接设备后使用系统文件管理器或设备管理软件；需要合适的数据线，具体可访问内容取决于手机系统 |
| [AirDrop（隔空投送）](https://support.apple.com/en-gb/119857) | 附近的 Apple 设备互传 | 从系统分享菜单选择接收设备；适合 Apple 设备之间便捷传送 |
| [Quick Share（快速分享）](https://support.google.com/android/answer/13801258?hl=zh-Hans) | 支持的 Android 与 Windows 设备互传 | Windows 端安装对应客户端，并确认设备、蓝牙和网络满足官方要求；不同厂商的兼容要求以官方说明为准 |
| [LocalSend](https://localsend.org/) | 经常跨平台互传，希望使用专用客户端 | 在参与设备上安装客户端，通过局域网传文件；不依赖互联网，项目提供 HTTPS 加密通信 |
| 网盘 / 云盘 | 异地发送、需要长期保存或分享链接 | 上传后分享给对方；依赖互联网，需考虑容量、账号权限和云端隐私 |
| 邮件 / 聊天工具 | 少量文件、顺手发给联系人 | 直接发送附件；大小、保存期限和图片压缩等限制取决于所用服务 |
| SMB 共享 / NAS | 长期共享资料、多人协作访问 | 配置共享目录与账号权限，接收设备通过文件客户端连接；更适合持续运行的文件服务 |
| 方序传文件 | 同一可信局域网，手机不想安装 App | 电脑双击启动并选择目录，手机扫码用浏览器上传、下载；传完即可停止服务 |

选择建议：附近的 Apple 设备可优先考虑 AirDrop；异地传输考虑网盘或邮件；长期共享考虑 NAS；**跨系统、临时共享目录、接收端只想用浏览器时，使用方序传文件。**

如果目标设备是 Kindle，或需要将书籍发送到 Kindle 云端书库，请参阅[方序传书 README](https://github.com/goldenwind/kindle-transfer/blob/main/README.md)，其中整理了 Kindle 浏览器下载、Send to Kindle、移动端分享和邮件传书方法。

## 下载

前往 [GitHub Releases](https://github.com/goldenwind/fangxu-file-transfer/releases/latest) 下载适合电脑系统的双击运行包。解压后即可启动，无需安装 Go；各平台的启动方式见下方“双击运行版”。

## 快速上手

1. 解压适合电脑系统的双击运行版，启动方序传文件。
2. 在电脑页面设置并应用共享目录（默认是当前用户的 `Downloads`）。该目录下的文件可被其他设备访问。
3. 让手机与电脑连接同一个 Wi-Fi；多人网络中先开启“访问令牌保护”。
4. 用手机扫码，在系统浏览器中打开页面：点击文件下载，或通过上传入口选择文件传到电脑。
5. 传输完成后，在电脑页面点击“停止传输服务”。看到服务已完全关闭的提示后，可以放心关闭页面。

## 工作方式

```text
电脑共享目录 <──同一 Wi-Fi / HTTP──> 手机或平板浏览器
```

- 数据只在局域网内流动，不上传第三方服务器。
- 手机无需安装 App。
- 电脑页面展示局域网服务器地址和对应二维码，手机扫码直接打开；移动端页面自动隐藏这些连接信息。
- 支持任意文件类型、中文文件名、子目录、搜索和 HTTP 断点续传；电脑和移动端网页均可一次选择多个文件上传到共享目录，同名文件会自动追加序号，不会覆盖原文件。
- 单次最多上传 100 个文件，总大小不超过 10 GB；上传未完成或失败时会自动清理临时文件。
- 文件可按大类和具体格式进行两级筛选，安装包按操作系统细分，PDF、Word 等阅读文档也会同时归入电子书；筛选项仅在有对应文件时显示，并带有文件数量。
- 隐藏以 `.` 开头的文件和目录；文件默认按时间从新到旧展示，可在下拉菜单中选择时间或名称的正序、倒序排列。
- 默认访问地址不设密码；在办公室、宿舍等多人网络中，可开启“访问令牌保护”。它相当于给共享链接加上一段专属密码，只有拿到完整链接或扫描新二维码的设备才能访问。
- 每次启动都会生成新的随机令牌，且保护开关默认恢复关闭。
- 电脑页面展示服务运行状态，并可点击“停止传输服务”安全退出。
- 电脑页面可直接输入并应用共享目录，也可打开系统文件夹选择器；切换后文件列表立即刷新，无需重启服务。
- 仅运行一个服务实例；再次双击会打开已运行的页面，不会重复占用端口或弹出进程错误。
- 网页仅提供上传与下载，不提供删除或重命名，避免误操作共享目录中的文件。

## 运行

需要 Go 1.22 或更新版本：

```bash
git clone https://github.com/goldenwind/fangxu-file-transfer.git
cd fangxu-file-transfer
go run . --dir "/需要分享的目录"
```

方序传文件会自动打开电脑端页面，并展示手机访问地址及二维码。让两台设备连接同一个 Wi-Fi，使用手机扫码即可开始传输。

不传 `--dir` 时默认共享当前用户的 `Downloads` 目录：

```bash
go run .
```

其他参数：

```text
--listen 0.0.0.0:9000  使用固定端口（默认自动选择空闲端口）
--no-open               不自动打开电脑浏览器
```

## 双击运行版

执行 `./build-packages.sh` 会在 `dist` 目录生成可以直接分发的版本：

| 平台 | 产物 | 使用方式 |
| --- | --- | --- |
| Windows x86-64 | `Fangxu-File-Transfer-Windows-amd64.zip` | 解压后双击 `双击运行.bat` 或 `Fangxu-File-Transfer.exe` |
| macOS Intel / Apple Silicon | `Fangxu-File-Transfer-macOS.zip` | 解压后双击 `方序传文件.app`；在打开的页面点击“停止传输服务”即可退出 |
| Linux x86-64 | `Fangxu-File-Transfer-Linux-amd64.tar.gz` | 解压后双击 `双击运行.sh` |
| Linux ARM64 | `Fangxu-File-Transfer-Linux-arm64.tar.gz` | 解压后双击 `双击运行.sh` |

双击运行时默认共享当前用户的 `Downloads` 目录。Windows 首次运行需允许防火墙访问“专用网络”；macOS 首次被系统拦截时，可右键 App 并选择“打开”。Linux 文件管理器可能需要先启用“将可执行文本文件作为程序运行”。

方序传文件已在运行时，再次双击启动项只会重新打开当前服务页面。macOS 启动器会立即退出，后台服务由页面上的“停止传输服务”按钮控制，避免 Finder 将应用误判为“没有响应”。

## 构建三个平台

在当前平台构建：

```bash
go build -o fangxu-file-transfer .
```

交叉编译示例：

```bash
mkdir -p dist
GOOS=windows GOARCH=amd64 go build -o dist/fangxu-file-transfer-windows-amd64.exe .
GOOS=darwin  GOARCH=arm64 go build -o dist/fangxu-file-transfer-macos-arm64 .
GOOS=linux   GOARCH=amd64 go build -o dist/fangxu-file-transfer-linux-amd64 .
```

## 常见问题

- 手机打不开地址：确认两台设备在同一 Wi-Fi；关闭 VPN/代理；允许程序通过 Windows 防火墙的“专用网络”；确认路由器未启用 AP/客户端隔离。
- 微信内无法下载：页面会自动显示提示。点击微信右上角“···”，选择“在浏览器打开”；iPhone 使用 Safari，Android 使用系统浏览器后再下载。
- 地址泄露：停止服务并重新启动，开启“访问令牌保护”后再分享新链接。仅重启而不打开保护开关，不能阻止他人访问不带令牌的地址。
- 公共网络：不建议使用。本工具采用局域网 HTTP，适合可信家庭或办公网络；敏感文件建议使用加密传输工具。
